## Сохранённое состояние

- Репозиторий: C:\Users\User\AndroidStudioProjects\ARMakeup, ветка codex/lipstick-material-v2.
- Код приложения соответствует ca80814 — [Tracking] Make non-blocking same-frame Sync the default. Очистка экспериментов сохраняет этот код; checkpoint документации см. git log.
- ARCore владеет камерой, MediaPipe выдаёт геометрию губ. Основной Sync неблокирующий: две GPU-текстуры pending/presented, один inference in flight, фон и материал используют exact camera/geometry pair. GL thread не ждёт callback. Async сохранён для ручного сравнения.

## Итог исследования границы и очистка

При сильном сжатии/подвороте и некоторых поворотах точность границы остаётся недостаточной. GPU-уточнение по цвету, офлайн-поиск контура и диагностика bundled blendshapes не дали принятого решения. Общее ослабление/исчезновение помады пользователь отклонил как замену точной границе.

Последняя проверка: на семи кадрах SM-G990B CPU/sensor/render timestamps совпали; наше преобразование координат и ARCore отличаются менее чем на 0.000220 px (CPU 640x480, rotation=270). Ошибочные точки видны уже на исходном CPU-входе MediaPipe. Дополнительного смещения ARCore/display mapping на проверенных кадрах не обнаружено. Дальнейшие эксперименты приостановлены по решению пользователя.

По команде «убери все лишнее и закоммить» удалены непринятое GPU-уточнение и переключатель, захват снимков по громкости вниз, CPU/GPU-диагностика, blendshape output/контракт и экспериментальные скрипты. Исходники приложения возвращены к ca80814. Прежняя диагностическая инфраструктура этого checkpoint, включая выключенный LipFrameTrace, сохранена.

32 локальных снимка и результаты остаются в gitignored captures/lip-boundary; не коммитить фотографии. Достаточные выводы сохранены в PROJECT_CONTEXT.md, экспериментальный код не является принятой основой.

## Правила продолжения

- До новой задачи не возобновлять работу над точностью границы, не повторять anchor/live-mesh и отклонённые contour/blendshape эксперименты, не подбирать коэффициенты вслепую.
- Новые готовые/собственные/дообученные ML-модели исключены по решению пользователя. Это ограничение времени и ресурсов, а не утверждение о запрете коммерческого использования всех готовых моделей. Существующий Face Landmarker сохранён; для новых SDK/assets остаётся license gate.
- Unit-тесты не добавлять и не запускать без команды. Обычный :app:assembleDebug разрешён. Коммит разрешён для этой очистки; push не запрошен.
- Расширенные device/latency/thermal проверки и ручное переключение Async/Sync остаются открытыми. Точная граница при сильном подвороте не прошла acceptance.
