# Repository guidance

Перед изменениями в проекте прочитайте `PROJECT_CONTEXT.md`.

- Главный продуктовый приоритет: максимально реалистичная виртуальная примерка макияжа в реальном времени.
- Не заменяйте GPU/ML-пайплайн простым 2D alpha overlay ради скорости реализации.
- Обновляйте `PROJECT_CONTEXT.md`, если меняются требования, архитектура, зависимости, performance budgets или принятые решения.
- Не добавляйте ML-модели и датасеты без явной проверки их лицензий и пригодности для коммерческого использования.
